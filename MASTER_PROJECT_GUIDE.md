## 4. How to Use Zora.ai (Product Feature Guide)

1. **Ask Anything (Live Web Search)**:
   - Type any question into the search bar (e.g. *"What are the latest breakthroughs in quantum computing this year?"*).
   - Zora.ai performs real-time internet search and returns formatted markdown answers with interactive **Source Citation Cards** (web links, titles, snippets).

2. **Upload Documents (Vector Knowledge RAG)**:
   - Click **"Attach RAG File"** or open **"Knowledge Base"**.
   - Upload any PDF, TXT, MD, or JSON file.
   - Ask questions about your file content (e.g. *"Summarize chapter 3 of my uploaded notes"*).

3. **Manage & Organize Chats**:
   - **Auto-Generated Titles**: Every new chat automatically gets a 2–4 word title generated by AI or prompt excerpts.
   - **Rename**: Click the **Pencil Icon** in the top header or sidebar menu to rename any chat.
   - **Delete**: Click the **Trash Icon** in the top header or sidebar menu to delete a chat.
   - **Pin**: Click the **Pin** option in the sidebar menu to keep important chats at the top.

4. **Share Conversations & Answers**:
   - Click the **Share** button on any message or in the chat header.
   - A glassmorphic **Share Modal** pops up displaying a public URL (`https://zora-ai-jew7.onrender.com/shared/...`).
   - Use **Copy Link**, **Open in New Tab**, or **Share via Device**.

5. **Download Notes as PDF**:
   - Click **Download PDF** under any response to save study notes as a printable PDF.

6. **Custom Themes**:
   - Click the **Theme** button in the header to switch between Cyan, Violet, Emerald, Amber, or Rose palettes.

## 5. Complete Setup Guide for PBL / College Defense / Handover

Give these exact instructions to anyone setting up Zora.ai from scratch:

### Prerequisites
- **Node.js**: v18 or higher installed
- **Git**: Installed
- **Docker Desktop**: Optional (if running via containers)

### Step 1: Clone Repository
```bash
git clone https://github.com/Rudrashrivastava/Zora.ai.git
cd Zora.ai
```

### Step 2: Set Up Backend Environment Variables (`backend/.env`)
Create a file named `.env` inside the `backend/` folder and add:
```env
PORT=8000
NODE_ENV=development
FRONTEND_URL=http://localhost:5173
BACKEND_URL=http://localhost:8000
MONGO_URI=your_mongodb_connection_string
GEMINI_API_KEY=your_gemini_api_key
MISTRAL_API_KEY=your_mistral_api_key
TAVILY_API_KEY=your_tavily_api_key
JWT_SECRET=your_jwt_secret
JWT_ACCESS_SECRET=your_jwt_access_secret
JWT_REFRESH_SECRET=your_jwt_refresh_secret
```

### Step 3: Install Dependencies
```bash
# Install Backend Dependencies
cd backend
npm install

# Install Frontend Dependencies
cd ../frontend
npm install
```

### Step 4: Run Development Servers
```bash
# Terminal 1: Run Backend (from backend/ directory)
npm run dev

# Terminal 2: Run Frontend (from frontend/ directory)
npm run dev
```
Open `http://localhost:5173` in your browser!

## 7. Production Bug Post-Mortems & Solutions

### ❌ Issue 1: Share Link Outputting `localhost:5173` on Render
- **Fix**: Added client-side URL rewriter in `Dashboard.jsx` (`openShareModal`):
  ```javascript
  if (fullUrl.includes("localhost")) {
      const parsed = new URL(fullUrl);
      fullUrl = `${window.location.origin}${parsed.pathname}`;
  }
  ```
  Backend also prioritizes `req.headers.origin` over static `.env` defaults.

### ❌ Issue 2: Chat Title Always Defaulting to `"New Chat"`
- **Fix**: `@langchain/google-genai` returned `response.content` as an array/object structure, throwing `TypeError` in `.replace()`. Fixed text extraction in `ai.service.js` with prompt excerpt fallbacks + MongoDB auto-repair on `getChats`.

### ❌ Issue 3: Share UI Displaying Native `alert()`
- **Fix**: Built an interactive **Share Modal** with read-only URL input, `"Copy Link"` button, hyperlinked text, and Web Share API.

### ❌ Issue 4: Sidebar Options Hidden Behind `opacity-0`
- **Fix**: Made sidebar 3-dots visible by default (`opacity-80`) and added direct **Rename (Pencil)** & **Delete (Trash)** buttons to the top header bar.

### ❌ Issue 5: High Concurrency Scaling (1,000+ Users)
- **Fix**: Added Mongoose Connection Pooling (`maxPoolSize: 50`) in `database.js` + B-Tree compound indexes on `{ user: 1, pinned: -1, updatedAt: -1 }` and `{ chat: 1, createdAt: 1 }`.

## 8. Master Technical Interview Script & Q&A

### 30-Second Elevator Pitch
> *"I built Zora.ai, a Full-Stack Real-Time AI Search & RAG Engine inspired by Perplexity.ai. It combines Live Web Search, Vector Document QA, Dual-AI Failover (Gemini + Mistral), and dynamic multi-theme React UI to deliver fast, cited, and accurate answers."*

### Key Interview Q&A

#### **Q1: How do you handle AI provider downtime or rate limits?**
> *"I implemented a Dual-AI Failover Architecture. Google Gemini is the primary provider. If Gemini fails or hits a rate limit, the error is caught asynchronously and the request automatically fails over to Mistral AI without breaking the user experience."*

#### **Q2: How did you solve the production share link bug?**
> *"I solved this using a 2-tier approach. Backend controllers inspect request headers (`origin`/`referer`). On the frontend, a URL sanitizer intercepts share URLs containing `localhost` and rewrites them using `window.location.origin`, guaranteeing valid production URLs (`https://zora-ai-jew7.onrender.com`)."*

#### **Q3: How did you optimize MongoDB for 1,000+ concurrent users?**
> *"I configured Mongoose Connection Pooling (`maxPoolSize: 50`) to reuse TCP sockets and added B-Tree compound indexes on `{ user: 1, pinned: -1, updatedAt: -1 }` for chats and `{ chat: 1, createdAt: 1 }` for messages, reducing query latency from $O(N)$ to $O(\log N)$."*

#### **Q4: How does authentication work?**
> *"Authentication uses short-lived access tokens (15 mins) and long-lived refresh tokens (7 days) stored in HTTP-only cookies. When an access token expires, Axios catches the 401 error, pauses pending requests, calls `/api/auth/refresh` to rotate tokens, and retries the original request seamlessly."*
